kitty

kitty 终端配置包。它把 kitty 设计成 tmux 的入口：启动后直接进入 tmux，并确保 Option/Alt、字体、颜色和 Homebrew 路径都符合终端工作流。

tmux 入口 Option as Alt Dracula 风格

安装

stow -S kitty

安装目标是 ~/.config/kitty/kitty.conf。由于默认 shell 是 tmux，更推荐一起安装：

stow -S tmux kitty

核心配置

  • allow_remote_control yes，允许远程控制 kitty。
  • macos_option_as_alt both，左右 Option 都作为 Alt/Meta。
  • GUI 启动时显式设置 PATH，避免拿不到 Homebrew 命令。
  • 默认 shell 是 /opt/homebrew/bin/tmux。
  • 字体是 LigaSauceCodePro Nerd Font，字号 14.0。
  • 颜色和 tab bar 走 Dracula 风格。
  • ctrl+1 到 ctrl+9 切换 kitty tab。

临时回到普通 shell

如果不想启动即进入 tmux，可以临时注释这一行：

shell /opt/homebrew/bin/tmux

这份配置默认 Homebrew 在 /opt/homebrew。Intel Mac、非 Homebrew 安装 tmux，或缺少 Nerd Font 时，都需要对应调整。
