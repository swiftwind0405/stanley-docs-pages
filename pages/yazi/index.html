yazi

Yazi 文件管理器配置包，覆盖主配置、键位、主题、插件和 Yazi 内使用的 Starship。它把文件浏览、预览、Git 状态、书签、压缩和跳转组织成一个键盘优先的工作流。

文件管理器 插件化 fzf / zoxide / ripgrep

安装路径

stow -S yazi

安装后主要文件在 ~/.config/yazi：yazi.toml、keymap.toml、init.lua、theme.toml、package.toml、starship.toml 和 plugins/。

主配置

  • 文件列表比例是 [1, 3, 4]。
  • 默认按文件名字母排序，目录优先。
  • 默认显示 size linemode。
  • 隐藏文件默认不显示。
  • 配置 macOS、Linux、Windows 的 open/reveal/edit 规则。
  • 图片、视频、PDF、字体、压缩包都有 previewer 或 preloader。
  • Git fetcher 已启用。

插件和状态栏

  • yaziline 状态栏。
  • starship，使用 ~/.config/yazi/starship.toml。
  • git 插件显示 Git 状态。
  • 右侧状态区显示当前文件 owner/group。
  • yamb 书签插件配合 fzf。
  • 声明插件还包括 smart-enter、compress 等。

键位分区

移动和进入

  • u/e：上/下移动。
  • n 或 Left：返回父目录。
  • i 或 Enter：smart enter。
  • N/I：后退/前进历史。
  • gg、G：到顶部/底部。

选择和文件操作

  • Space：选择当前项并下移。
  • v：进入选择模式。
  • yy / dd：复制 / 剪切。
  • p p / p P：粘贴 / 覆盖粘贴。
  • d D：永久删除。
  • T / M：创建文件 / 目录。
  • a、A、k、cw：不同方式重命名。

查找、跳转和插件

  • Ctrl+p：fzf 跳转目录或 reveal 文件。
  • z o：zoxide 跳转。
  • F：ripgrep 搜内容。
  • f、/、?：过滤或查找。
  • g h/d/D/c：跳到常用目录。
  • g f y：跳到 Yazi 配置目录。
  • ' a、' '、' r：保存、跳转、删除书签。
  • c a：压缩选中文件。
  • Ctrl+g：当前目录打开 lazygit。

需要 yazi，插件管理依赖 ya pkg。推荐安装 fzf、zoxide、ripgrep、fd、starship、lazygit。图片和特殊格式预览可能还需要 magick、mpv、mediainfo、exiftool，图标依赖 Nerd Font。
