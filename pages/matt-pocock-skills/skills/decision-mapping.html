/decision-mapping

面向用户的技能文档 skills/in-progress/decision-mapping/SKILL.zh-CN.md

当松散想法需要多个 agent session 才能变成计划时调用本 skill。它在 markdown 文件中创建有状态的 decision map，并驱动用户按序 resolve 开放问题 — 可能需要 prototype、research 或 discussion。

The Decision Map

decision map 是单个紧凑 Markdown 文件，每个规划 effort 一份，与项目一起 git-track。它是 canonical artifact — 整张 map 作为 context 载入每个 session，因此必须保持 compact。

ticket 期间创建的 asset 应从 map link，不要在 map 内 duplicate。

Structure

编号条目（「ticket」），每条以编号为 key 的独立 section：

## #1: Relational Or Non-Relational Database?

Blocked by: #<ticket-number>, #<ticket-number>
Type: Research | Prototype | Discuss

### Question

<question-here>

### Answer

<answer-here>

每个 ticket 须能在一个 100K token agent session 内完成。

Ticket Types

三种 ticket 类型：

  • Research：读文档、第三方 API 或本地资源如 knowledge base。创建 markdown summary 作为 asset。需要当前工作目录外知识时用。
  • Prototype：写 UI 或 logic 代码测试 hypothesis 或探索设计空间。使用 /prototype skill。创建 prototype 作为 asset。当「应该长什么样」或「应该如何行为」是 key question 时用。
  • Discuss：与 agent 对话。使用 /grilling 和 /domain-modelling skill。默认情况。

Fog of war

map 在 frontier 之外 刻意 不完整。你的工作是调查 frontier，按序 resolve ticket 以推进 frontier。一次推回一个节点的 fog of war。

Eventually fog of war 应被推得足够远，终点路径 clear。那时不再需要 ticket，decision map 可视为「done」。

Invocation

本 skill 有两种调用方式：bootstrap 和 resume。

Bootstrap

用户以松散想法调用。

  1. 运行 /grilling 和 /domain-modelling session 以 surface 开放决策。
  2. 写新 decision map — 多为 fog，frontier 已识别，trivially-decidable 条目 inline resolve。
  3. 停止。建 map 是一个 session 的工作；不要同时 resolve ticket。

Resume

用户传入现有 map 路径和 ticket 编号。

  1. 将 整张 map 作为 context 载入。
  2. 运行 session resolve ticket，按需 invoke skill。不确定时用 /grilling 和 /domain-modelling。
  3. 在 ticket body 记录 session resolve 的内容。
  4. 添加新发现的 ticket（带正确 blocked_by 边）。
  5. 停止。

若所做决策使 map 其他部分 invalid，更新或删除那些节点。

Parallelism

用户可能选择并行跑 ticket，因此 expect 其他 agent 会改 map。

Skipping The Decision Map

很多时候，初始 grilling 结果没有 fog of war。无 unresolved ticket。无事可做，除了 implement。

此时应 offer 用户跳过 decision map 的机会 — 因为 decision map 仅在需要多 session 决策时才需要。

若他们跳过，应建议直接 implement 或用 /to-prd 安排多 session implementation。
