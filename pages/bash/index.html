bash

Bash 启动配置包。它不是主力 shell，而是给仍会进入 Bash 的场景保留一层基础环境：本地命令路径、Volta、Fig hook 和 VS Code CLI。

兼容层 macOS 路径 Fig 可选

安装

stow -S bash

会安装 ~/.bashrc 和 ~/.bash_profile。

~/.bashrc

  • 加载 Fig 的 pre/post shell hook。
  • 设置 VOLTA_HOME="$HOME/.volta" 并加入 PATH。
  • 把 ~/.local/bin 放进 PATH，方便使用 bin 包命令。

~/.bash_profile

  • 加载 Fig hook。
  • 加入 VS Code CLI 路径。
  • 加入 ~/.local/bin。
  • 保留 Maven、JetBrains、Volta 等历史配置注释。

重新加载

source ~/.bashrc
source ~/.bash_profile

这套配置明显偏 macOS，尤其是 /Applications/Visual Studio Code.app/...。如果日常主要用 zsh，把它当作兼容入口就好。
