§1

这是什么

把 HR 月度考勤重复劳动自动化

这 9 个 skill 把 HRO 外包场景下「原始考勤资料 → 归档 → 异常审核 → 生成考勤备注 → 交付」的月度流程拆成可复用的环节。每个环节单独可跑，串起来就是一条流水线。

两条主线交叉：一条是数据流水线（下方 §2），一条是客户分型 A/B/C/D（§3）—— 不同客户的考勤系统不同，用到的 skill 组合也不同。先看 §2 的总流程，再用 §3 对号入座，最后点 §4 的卡片进每个 skill 的详情。

LANE · 红

入口与编排

分诊选客户、月度全流程门禁。triage · monthly-reconcile · laoqin-monthly

LANE · 蓝

数据准备

抽附件、视觉识别、按人归档、来源归一。data-prep · source-normalizer

LANE · 绿

审核与计算

异常审核工作簿、生成考勤备注与审核报告。exception-review · remarks

LANE · 琥珀

配置与交付

规则书面化为 config、交付齐套检查。rule-pack · delivery-pack

§3

客户分型 · 对号入座

不同考勤系统 → 不同 skill 组合
A

数据员宽表型

代表客户：追觅
数据员按月导出考勤汇总宽表（常无身份证），按考勤部门拆表，80% 飞书打卡。靠按人截图核对闭环。
monthly-reconcile data-prep exception-review remarks
B

钉钉导出 + 异常凭证型

代表客户：珠海基石 · 奥托立夫
钉钉考勤报表 + 大量 .msg 补卡/加班/出差/请假凭证。重点是把散落凭证归一为可审计来源。
source-normalizer exception-review remarks rule-pack
C

内置核算 + 书面规则型

代表客户：启云方
钉钉内置核算 + 书面规则 docx（班次、欠工时、加班核算、忘打卡）。重点是把书面规则落成可复核 config。
rule-pack exception-review remarks
D

系统 PDF + 确认单型

代表客户：国家电投 / 核电
客户自有劳勤 WTS，逐人导出考勤 PDF，按科室填 Excel 并回填工作量确认单，靠科室确认单闭环。
laoqin-monthly data-prep exception-review delivery-pack
