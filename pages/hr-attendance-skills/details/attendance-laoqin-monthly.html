劳勤月度考勤（核电类）

attendance-laoqin-monthly
⚛️
入口与编排 skills/attendance/
把「顾问名单 → 劳勤 WTS 逐人导出 PDF → 科室 Excel 汇总 → 确认单回填 → 科服交付」的月度流程标准化。本 skill 只负责流程编排与阶段门禁；PDF 归档交 data-prep、PDF 读取交 pdf-llm-preprocess、公式/单据异常交 exception-review。
◧

FIT & CLIENTS

适用画像 / 试点 / 不适用
D适用画像
客户自有劳勤 WTS 考勤系统（非飞书/钉钉宽表）；按客户科室/车间组织（非「考勤部门」）；主交付员工考勤 PDF + 「人员工作量及考核结果确认单」；靠科室确认单闭环，不逐一截图核对。
✦试点客户
国家电投 / 核电（PMC North Qing wu）。21 个科室，各科一份确认单模板。
✗不适用
追觅类数据员宽表流程 → 改用 monthly-reconcile，勿套用按人截图、飞书凭证。

  • 回填的「人员工作量及考核结果确认单」
  • 交付科服：PDF 文件夹 + 确认单 + 加班说明

CONFIRMATION COLS

确认单关键回填列
出勤工作日天数
科服津贴据此计；阶段 5 回填时单独标注。
公休日加班小时数 / 延长工作时间小时数 / 法定节假日加班小时数
三项加班口径，分别对应 Excel 标黄列、延长工时列、法定假日行。
已执行/计划执行换休小时数
含计划换休，从合计中扣减；勿只算已执行。
计算加班费小时数（本月合计）
由上述三加班项减换休得出，须顾问书面确认后写入 attendance_config.json。

PHASE GATES

阶段门禁（必须按序）7 阶段 0–6 · 不可跳门
  1. 0
    收名单与确认单GATE
    约每月 10–11 日接收。各科模板齐全；已核对跳过名单已标记。
  2. 1
    科室筛人 + 账号GATE
    按科室打开顾问名单（如「生产技术部-结构科」），复制每人劳勤工号/密码，与确认单模板逐一比对。门禁：本科室人员与确认单行数一致。
  3. 2
    劳勤导出 PDFGATE
    逐人登录 WorkbenchCalendar 切月份，看汇总（出勤/差旅/加班/审批状态），打印保存 PDF，文件名=员工姓名。门禁：每人有 <姓名>.pdf（出差另有单据）。
  4. 3
    填科室 ExcelGATE
    标黄周末加班、法定假日行、批注加班转调休；差旅>0 走出差分支。门禁：日出勤/加班/调休与劳勤一致。
  5. 4
    加班费合计GATE
    公休日 + 延长工时 + 法定节假日 − 已执行/计划执行换休小时数。门禁：公式已按月调整；合计列已算。
  6. 5
    回填确认单GATE
    Excel 汇总列复制到确认单对应行，标注出勤工作日天数。门禁：各科确认单与 Excel 一致。
  7. 6
    交付科服GATE
    各员工考勤 PDF 文件夹（含出差单据）+ 各科签字确认单 + 加班情况说明。门禁：PDF 夹 + 确认单已发出。
禁止
  • 未导出劳勤 PDF 就填确认单。
  • 未处理出差单据就交付科服。
  • 跳过公式按月（30/31 天）调整。
⊟

LAOQIN SYSTEM

劳勤系统操作与状态口径
系统路径
劳勤 WTS 4.0 → 考勤日历 WorkbenchCalendar。登录需账号 + 密码 + 验证码；切换用户 = 右上角退出后下一员工登录。
延长工作时间审批中
员工已申请、领导未批 —— 仍按申请/实际时长填 Excel，不因审批未过而漏记。
双休日加班
表现为日历橙色格；填 Excel 时该列标黄（公休日加班）。
差旅 > 0
进入阶段 3 出差分支，须导出出差审批 PDF 与考勤同目录归档。
✈

TRAVEL & FORMULA

出差分支与 Excel 公式注意
  1. 1
    打开已通过出差申请单据
    在劳勤中定位该员工已审批通过的出差申请。
  2. 2
    展开跨月全部时段
    确保跨月出差的所有时段都展开可见。
  3. 3
    导出出差审批 PDF
    与考勤 PDF 同目录命名：姓名.pdf + 姓名-申请单据.pdf。
公休日 / 工作日加班列
有公式，每月须按 30/31 天调整，否则合计偏差。
调休列
无公式，手工记录（批注加班转调休，如 7.5h）。

OVERTIME TOTAL

加班费合计公式
计算加班费小时数（本月合计）
  = 公休日加班小时数
  + 延长工作时间小时数
  + 法定节假日加班小时数
  − 已执行/计划执行换休小时数

RUN

运行命令（编排调用下游）
RUN · 会话入口变量 + 下游 skill
DATASET_NAME="PMC North Qing wu 国家电投考勤"
PAY_PERIOD="<YYYYMM>"
SOURCE_DIR="data/raw/${DATASET_NAME}"
OUTPUT_DIR="outputs/${DATASET_NAME}-${PAY_PERIOD}"

# 1. 按人/科室归档劳勤 PDF（推荐）
uv run python skills/attendance/attendance-data-prep/scripts/prepare_attendance_data.py \
  "${SOURCE_DIR}" "${OUTPUT_DIR}" \
  --base-table <顾问名单.xlsx>

# 2. PDF 视觉/文本预处理（辅助读取出勤加班）
uv run python skills/utility/pdf-llm-preprocess/scripts/pdf_llm_preprocess.py \
  "${OUTPUT_DIR}/考勤PDF/<科室>/<姓名>.pdf" \
  --out-dir "${OUTPUT_DIR}/pdf_pages/<姓名>"

# 3. 异常审核（审批中、出差缺单据、公式不平）
uv run python skills/attendance/attendance-exception-review/scripts/build_exception_review.py \
  "${OUTPUT_DIR}" "${PAY_PERIOD}" \
  "${OUTPUT_DIR}/exception_review.xlsx" \
  --source-dir "${SOURCE_DIR}" \
  --config <attendance_config.json>

RETRY & NOTES

失败重试 / 注意事项
登录/导出失败
记录失败人员单独重试，不跳门继续汇总。
PDF 识别失败
先跑 data-prep / pdf-llm-preprocess 修复后再回填确认单。
合计不一致
回到对应科室 Excel 逐行核对，不直接交付科服。
域名/界面变更
以顾问最新 SOP 为准（视频为 att.snpmc.com），不沿用过期录屏。
21 个科室模板
结构应一致，差异须记录在 rules_catalog_draft.md。
操作视频
两段内容基本一致，处理一份即可。
