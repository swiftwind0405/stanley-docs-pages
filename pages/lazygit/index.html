lazygit

lazygit 的 UI、pager 和键位配置。它把 Git TUI 调成暗色、低确认、带 Nerd Font 图标的高频操作界面，并让方向键风格贴合仓库里的 tmux 和 yazi。

delta pager Nerd Font n/e/u/i 键位体系

安装

stow -S lazygit

配置会落到 ~/.config/jesseduffield/lazygit/config.yml。

体验取向

  • 关闭退出确认。
  • Git 自动 fetch。
  • 合并时不强制 manual commit。
  • 用 delta 作为 pager。
  • 关闭 reporting。
  • UI 使用 rounded border、暗色主题和 Nerd Font 图标。
  • 顶层按 Return 直接退出。

关键键位

  • Alt+u/e：上一项/下一项。
  • Alt+n/i：上一个/下一个 block。
  • =、-：下一个/上一个搜索结果。
  • k：新建。
  • o、O：编辑、打开或交互式 rebase。
  • l、Ctrl+r：undo/redo。
  • M、Ctrl+f、v：diff menu、filter menu、range select。

需要安装 lazygit。如果没有 delta 或 Nerd Font，diff 和图标显示会降级或失败。
