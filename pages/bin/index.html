README 目录 / bin

bin

自定义命令集合，统一安装到 ~/.local/bin。zsh 和 bash 包都已经把这个目录加入 PATH，所以这里更像个人工具箱的入口层。

~/.local/bin Codex 辅助 tmux 友好

安装

stow -S bin

命令地图

  • agent：薄封装，转发到 ~/.config/agent-tracker/bin/agent。
  • ai-mem-usage：统计 opencode、dart 相关进程内存，并尝试映射到 tmux pane/window。
  • ask：用隔离临时 CODEX_HOME 调用 Codex CLI，支持 prompt 文件和图片。
  • nvim-lazy-reset：重置 ~/.local/share/nvim/lazy 下所有 lazy.nvim 插件。
  • pinchtab-up：检查并启动 PinchTab，优先 daemon，失败后回退后台 server。

常用命令

agent --help
ai-mem-usage
ask --prompt-file prompt.txt
ask --prompt-file prompt.txt -i screenshot.png
nvim-lazy-reset
pinchtab-up

nvim-lazy-reset 会丢弃插件目录里的本地改动；ask 依赖 Homebrew 路径下的 Codex 和 ~/.codex/auth.json；agent 需要先构建 agent-tracker。
