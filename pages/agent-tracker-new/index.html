agent-tracker

一个和 tmux 深度联动的 agent 任务、通知和状态追踪工具。这个 dotfiles 包负责把源码、配置、构建脚本和 tmux 辅助脚本放到 ~/.config/agent-tracker。

Go 构建 tmux 通知 和 bin 包配合

安装路径

stow -S agent-tracker

安装后重点看这几处：agent-config.json 管键位、设备和状态栏开关；install.sh 构建 tracker-server、tracker-mcp 和 agent；scripts/ 提供 tmux 聚焦通知、brew service 安装和测试脚本。

典型流程

  1. 先 stow 这个包，把源码和配置链接到 ~/.config/agent-tracker。
  2. 执行 ~/.config/agent-tracker/install.sh 构建二进制。
  3. 需要常驻服务时，再运行 scripts/install_brew_service.sh。
  4. 同时安装 bin 包，让 ~/.local/bin/agent 转发到真正的 agent 可执行文件。
stow -S agent-tracker bin
~/.config/agent-tracker/install.sh

tmux 集成点

  • client attached、pane focus、window select 时确认通知。
  • pane 退出时删除对应任务。
  • M-s 打开 agent palette，M-m 聚焦最近通知 pane，M-M 回到通知来源 pane。
  • prefix 后按 P 切换通知状态。

依赖 Go 和 tmux。方向键采用 n/e/u/i 风格，和仓库里的 tmux、yazi、lazygit 键位体系保持一致。
