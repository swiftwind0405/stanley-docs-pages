raycast-scripts

Raycast Script Commands 包，用几个 shell 脚本切换 Claude Code 相关的声音提示状态。状态通过 ~/.claude 下的 flag 文件表达。

Raycast Claude Code TTS 控制

安装和接入

stow -S raycast-scripts

然后在 Raycast 中添加 Script Commands 目录：

~/.config/raycast-scripts

脚本职责

  • claude-code-ring-toggle.sh：切换 ring mode，对应 ~/.claude/ring-enabled。
  • claude-code-voice-toggle.sh：切换 voice mode，对应 ~/.claude/voice-enabled。
  • stop-voice-tts.sh：停止所有 say 进程，用来打断系统 TTS。

ring mode 和 voice mode 互斥：开启 ring mode 时会删除 voice flag。脚本依赖 macOS 的 say 进程名和 Raycast Script Commands 功能。
