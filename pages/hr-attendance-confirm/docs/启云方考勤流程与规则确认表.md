### 2. 月中异常催办：我们理解的异常分类

> 来源：考勤报表「含步骤」sheet。请确认分类是否完整、登记口径是否正确。

| 编号 | 异常类型 | 我们理解的处理方式 | 确认 |
| --- | --- | --- | --- |
| ① | 上班+下班都缺卡 | 登记「请假电子流待闭环」或统一写「需提醒员工处理闭环」 | ☐ |
| ② | 上班缺卡 | 查电子流是否有补卡/外出；有则「补卡/外出电子流待闭环」 | ☐ |
| ③ | 下班缺卡 | 同上 | ☐ |
| ④ | 早退但上班正常 | 「请假电子流待闭环」 | ☐ |
| ⑤ | 迟到（弹性班次） | 核心时段迟到较短（≤1h）视为真迟到，可不追问修复；否则补卡闭环 | ☐ |
| ⑥ | 出差 | 有打卡可不走外出电子流；无打卡须「需提醒提交外出电子流」 | ☐ |
| ⑦ | 休息日疑似加班 | 筛选班次列，应休息时若有正常上下班卡，提示发起加班电子流（夜班除外） | ☐ |
| ⑧ | 截止日未打下班卡 | 如 26 日下午导出，当日周末加班可能尚未下班打卡 | ☐ |
| ⑨ | 半天请假下午返岗 | 须打上班卡+下班卡；原始记录与每日统计可能不一致需人工对 | ☐ |
| ⑩ | 原始记录备注换班次 | 需结合备注调整统计 | ☐ |
| ⑪ | 外出公干含休息日 | 算正常休息，不额外处理 | ☐ |

**简化口径**：是否允许异常统一登记为「需提醒员工处理闭环」？ ☐ 允许 ☐ 不允许，必须细分

### 4. 书面规则 v1.0：我们理解的核心规则

> 摘自 `启云方(在岸服务外包)考勤及费用结算规则-v1.0定稿版.docx`，请确认是否为现行有效版本。

| 规则域 | 我们理解 | 确认 |
| --- | --- | --- |
| 班次类型 | 固定班次 A/B/E、白班/夜班/白班2/夜班2/白班3；弹性 C（弹1H）、D（弹0.5H） | ☐ |
| 工作日历 | 正常工作日历 vs 非正常（排班制） | ☐ |
| 加班认定 | 加班流程与有效打卡记录的**交集**；不跨天按次日 05:00 切日，跨天按 12:00 切日 | ☐ |

| 迟到/早退（弹性班） | 核心时段迟到须含弹性时段时长 | ☐ |
| 费用结算 | 人天单价制：(工作日出勤 + 加班×0.8) ÷ 8 × 人天单价 | ☐ |
