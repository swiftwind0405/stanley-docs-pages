## 一、请确认：以下流程理解是否正确

请在每项后标注 **✓ 正确** / **✗ 有误（请说明）** / **△ 部分正确**。

### 1. 每月整体顺序

| 序号 | 我们理解的步骤 | 确认 |
| --- | --- | --- |
| 1 | 先导出**当期应发薪花名册**（含离职但当月仍计薪人员，不能仅用「在职」） | ☐ |
| 2 | 从顾问处获取各**考勤部门**当月人员清单，为花名册补充「考勤部门」 | ☐ |
| 3 | 新增员工：通过比对「本月出现在哪张考勤表」判定所属考勤部门 | ☐ |
| 4 | 收到数据员原始考勤表后，**先复制保留原始版**，再在工作副本上补身份证号、职位 | ☐ |
| 5 | **先对人头**（与花名册人数比对），确认无误后再改考勤数据 | ☐ |
| 6 | 整理数据员表：隐藏零值列 → 请假列只留事假/调休假 → **调休假天数加入实际出勤** | ☐ |
| 7 | 首次发放前**不预扣迟到早退**，等员工反馈后再处理 | ☐ |
| 8 | 按人截图（员工行到「总计」）+ 画数模板，发给员工核对 | ☐ |
| 9 | 员工回复「核对无误」即通过；有问题则凭飞书截图等凭证改表 | ☐ |
| 10 | 改表后须员工二次确认「核对无误」，再打包给 HR/客户审核 | ☐ |

### 2. 首次发放前的数据整理规则

| 规则 | 我们理解 | 确认 |
| --- | --- | --- |
| 隐藏列 | 整列求和为 0 的列隐藏（如严重迟到、旷工等本月无数据列） | ☐ |
| 请假列 | 只保留「事假」「调休假」，其他假期列隐藏 | ☐ |
| 调休假 | 调休假天数 **加到**「实际出勤天数」（因系统实际出勤不含调休） | ☐ |
| 事假含义 | 表上统一显示「事假」，年假/月假等需事后追问员工并记入特殊事项表 | ☐ |
| 迟到早退 | 首次发放不处理；员工反馈后再按规则扣减 | ☐ |

### 3. 员工反馈后的常见问题处理

| 场景 | 我们理解 | 确认 |
| --- | --- | --- |
| 加班核对 | 员工提供**飞书考勤日历**截图；HR 按考勤部门班次规则重算工作日加班 | ☐ |
| 工作日加班公式 | 实际下班时间 − 规定下班时间 − 晚餐 0.5 小时 | ☐ |
| 周末加班 | 飞书日历有「小月亮」= 周末加班已审批；仍须看加班申请里「是否关联调休」 | ☐ |
| 关联调休 | 「是」→ 整天计入关联调休；「否」→ 计入不关联调休（付加班费）；一天不拆分 | ☐ |
| 夜班 | 跨天打卡（Day1 上班 + Day2 下班），需往后串一天看下班时间；顾问月初提供名单 | ☐ |
| 公出 | 有出勤天数但无打卡时间，需员工提供**每日**打卡截图 | ☐ |
| 迟到 | 有迟到/早退且未补卡未请假 → 扣 **0.5 天**出勤（夜班误显迟到除外） | ☐ |
| 年假 | 事假实为年假时，须查员工请假邮件；年假由 HR 线下台账管理 | ☐ |
