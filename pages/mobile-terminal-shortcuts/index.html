iPhone / iPad 终端快捷键配置

这套布局配合当前的 Agent Tracker、tmux、Vim 和 Zsh 使用。按键名称完全来自终端应用的固定键池；页面里的中文只解释用途，不是自定义键名。

固定键池 tmux prefix：^S Agent 三 pane 布局 Zsh vi mode

配置原则

手机主要用来查看任务状态、切换 session、聚焦 pane 和临时接管命令。最高频的方向键、回车、esc、tab、退格、paste、^C 放在最前面，并把方向键围绕回车排成十字。符号键与 F6–F24 可以从常用区移走。

直接选择 New Group 组合 session 切换

绿色键沿用现有 Alt-r 的组合方式。创建后以应用预览栏显示的结果为准，不要手工输入键名。

New Group 怎么建

  1. 打开 Additional keyboard，进入 Customize，新增一个 Group。
  2. 先选 alt，再选对应的 ^X。比如 Alt-r 使用 alt + ^R。
  3. 检查顶部预览栏。只有预览结果与目标组合一致时才保存。
  4. 把新 Group 拖到推荐位置。绿色区的 8 个组合依次是 Alt-s、Alt-a、Alt-g、Alt-r、Alt-f、Alt-l、Alt-w、Alt-b。

按键用途

键用途使用方式
^Stmux prefix后面继续按 tmux prefix 表里的键。
^N / ^P下一个 / 上一个 window依次按 ^S、^N，或 ^S、^P。
F1–F5切换 session 1–5tmux 已配置为全局键，单击即可切换。
Alt-s打开 Agent Palette查看任务、启动 Agent 或进入 Tracker。
Alt-a / Alt-g / Alt-r聚焦 AI / Git / 运行 pane适合当前左侧 AI、右上 Git、右下运行的布局。
Alt-f缩放当前 pane再次按下恢复原布局。
Alt-l上一个 window需要向后切换时直接按；向前切换用 ^S、^N。
Alt-w切换 pane 监看用状态栏标记需要持续观察的进程。
Alt-b切换未读标记手动标记或清除当前 window 的未读状态。
^RZsh 历史搜索打开当前配置里的 fzf history widget。
esc退出 Vim insert mode / 返回Zsh 使用 vi mode，Agent Tracker 也用它返回上一层。
?显示帮助Agent Tracker 和部分 TUI 中可查看当前键位。
^Q恢复终端输出在 tmux 外误按 ^S 后，如果终端像卡住了就按它。

Agent Tracker 操作

  • Alt-s 打开 Agent Palette。
  • 使用箭头选择项目，↵ 打开。
  • esc 返回，? 查看帮助。
  • 进入具体 pane 后，用 Alt-a、Alt-g、Alt-r 在三块区域间跳转。

Vim / Zsh 操作

  • esc 是最常用的模式切换键。
  • ^C 中断命令，^W 删除前一个单词，^L 清屏。
  • ^R 搜索历史命令。
  • 长命令和代码仍用 ABC 键盘输入，快捷面板只负责控制动作。

固定键池的限制

当前选择器没有普通的 m、e、u、i、y、v，因此不能从快捷面板做出一键 Alt-m、Alt-M、Alt-e、Alt-u、Alt-i、Alt-y、Alt-v Group。

这些键仍可通过 alt 修饰键配合 ABC 键盘输入，只是不能占用一个单独的自定义按钮。Alt-m 和 Alt-M 对应 Agent Tracker 的最近通知与返回来源，需要时用这种方式操作。

^S 在 tmux 内是 prefix，在普通终端里可能触发软件流控。终端停止输出时按 ^Q 恢复。

可以移除的键

常用区不需要重复的 esc、tab、paste、^C、home、end，也不需要 F6–F24、ins、del 和整块符号键。/ 与 | 留在最后一行，方便临时输入路径和管道。
