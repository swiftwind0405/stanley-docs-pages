ce-promote

将已发布的功能转变为可复制粘贴、面向用户的公告副本 - 就在工程工作流程中。默认情况下与螺旋无关；安装 Spiral CLI 后进行语音匹配。

ce-promote 是 发布后消息传递 技能。功能合并后，它会计算出发布的内容，选择正确的渠道，并起草公告副本 - X 帖子或线程、单行变更日志简介、LinkedIn 帖子、电子邮件、博客介绍、简短的演示脚本。它无需安装任何内容即可生成良好的副本，并在存在并经过验证时使用 Spiral CLI 进行品牌语音匹配的草稿。

它只是草稿。它从不发布、发布、提交或打开 PR——发送副本是人为行为。

＃＃ 问题

消息传递通常需要等待单独的营销通行证，因此它落后于船舶 - 并且最了解用户价值的工程师并不是编写副本的人。当公告文案是临时编写的时，它倾向于人工智能告诉（“我们很高兴宣布……”）、主题标签垃圾邮件和实施言论，而不是用户价值。

解决方案

ce-promote 在发货时根据发货上下文起草副本：

  • 从自由格式的描述或合并的 PR、差异、变更日志和最近的提交中得出发布的内容 - 然后总结面向用户的价值，而不是代码。
  • 明智地选择渠道（默认情况下是 X 帖子 + 变更日志简介）并根据用户的要求和变更的需要进行扩展。
  • **准备好后，通过 Spiral 起草配音副本；如果没有，则提供一次设置（登录或安装），并且在下降时利用编辑和社交媒体基础知识的精简层来自行起草强大的特定于渠道的副本。
  • 呈现草稿供审阅 - 可复制粘贴，按频道标记，从未发布。

是什么让它如此新颖

1. Spiral 作为一种微妙的、可选的增强——绝不是依赖

Spiral 被检测为三种状态 (which spiral + spiral auth status --json)：就绪、已安装但未授权或不存在。准备就绪后，草稿将与用户的品牌进行语音匹配，并保留到他们的 Spiral 帐户（每个草稿都带有一个用于调整的网络应用程序 url）。未准备好时，该技能会提供一次设置 - 如果已安装但未经身份验证，代理将运行 spiral login 并共享登录链接（您在浏览器中批准 - API 密钥永远不会触及代理）；如果缺少，则指向一步安装命令 - 拒绝总是好的：它会退回到编辑和社交媒体专业知识的精简层，自行起草强大的副本，并记录选择退出，这样就不会再烦人了。无论有或没有螺旋，该技能都同样有用。

2. 多通道/提示词陷阱已编码

Spiral 的多通道行为是短语驱动的，而不是标记驱动的，并且它具有技能明确处理的锋利优势：

  • 一个频道的 N 个变体 → 要求“3 个推文选项”，避免提示词（campaign、across、multi-channel、everywhere、cross-post），并传递 --num-drafts 3。一个杂散的提示词会触发战役模式并将输出折叠为一个草稿，默默地忽略 --num-drafts。
  • 真正的跨渠道集 → 在提示中命名渠道； Spiral 返回每个通道的一组草稿 — 它决定计数，通常是几个 — 并且 --num-drafts 被忽略。一次调用即可生成整个跨通道集。

3. 仅限草稿 — 发帖始终由人工完成

该技能从不发布、安排、发布、提交或打开 PR。输出始终是可供审阅的草稿。这使得人们能够参与到一个向外且难以逆转的动作中。

4. 用户价值高于实施

“发布了什么”摘要描述了用户现在可以做什么以及他们为什么关心——而不是使之成为可能的序列化器或端点。直接起草禁止人工智能告诉、清嗓子和标签垃圾邮件，并将长度/音调与每个频道相匹配。

简单示例

您可以合并 PR，添加一键 CSV 导出。

单通道变化： /ce-promote 3 tweet options for the new one-click CSV export → 技能总结了值，然后（螺旋路径）运行 spiral write "3 tweet options for one-click CSV export" --instant --num-drafts 3 --json ，没有提示词，或者（无螺旋路径）直接写入三个不同的推文。所有这三个都以可复制粘贴块的形式呈现。

跨通道集合： /ce-promote draft a launch across X, LinkedIn, and email → (螺旋路径) spiral write "announcing one-click CSV export — a launch across X, LinkedIn, and email" --instant --json 返回每个通道的一组草稿(螺旋决定计数)； （无螺旋路径）该技能直接起草一篇 X 帖子、一篇 LinkedIn 帖子和一封电子邮件。每份返回的草稿都按通道标记并准备复制。

何时去实现它

在以下情况下使用 ce-promote：

  • 一项功能刚刚发布，您希望在上下文消失之前起草公告
  • 您需要通过一个提示进行跨渠道文案（推文 + LinkedIn + 电子邮件）
  • 您想要语音匹配的副本并安装了 Spiral

在以下情况下跳过它：

  • 没有提供任何面向用户的内容（内部重构、仅 CI、仅测试）
  • 您只需要内部发行说明 - 使用 /ce-release-notes 作为插件发行历史记录
